# AEGIS SENTINEL

<img src="logo_white.png" width="500px"/>

Aegis-Sentinel is an advanced multi-sensor airspace surveillance and early-warning system designed to detect, classify, and precisely geolocate aerial threats across the low-altitude domain. Acting as an aerial Intrusion Detection System (IDS), it integrates passive acoustic sensing with LiDAR and radar to identify and track airborne objects of any size, including UAVs, loitering munitions, and conventional aircraft. Through real-time sensor fusion and signature analysis using machine learning, the platform delivers high-confidence detection, trajectory estimation, and persistent situational awareness, enabling rapid threat identification and enhanced airspace security for military and critical infrastructure environments.

The minimal deployment unit consists of three distributed acoustic sensor nodes operating as a triangulation array, coupled with a centralized control unit that performs real-time signal correlation and sensor fusion. This configuration enables precise source localization of aerial objects and continuously streams processed tracking data to connected defense or countermeasure systems for rapid response and threat mitigation.
